# Visual QA Audit — Quantocos / GC³ (v1)

> **Historical document.** This audit predates the final redesign. See [final-report.md](final-report.md) for the current scorecard, architecture and verification.

## 1. Stack identification

| Aspect | Value |
|---|---|
| Framework | **None.** Plain HTML/CSS/JS, generated by a Python static-site builder (`build_q.py` → `build.py`, `q_pages_*.py`, `render.py`). |
| Styling method | Hand-written CSS in `assets/css/`: `site.css` (structure/components), `theme.css` (brand overrides), `brand.css` + `tokens.css` (**generated** from `theme.py`), `motion.css` (animation + data-flow diagrams), `layouts.css` (layout-only layer). No Tailwind, no preprocessor. |
| Fonts | Headings: **Segoe UI** (system face, no download). Body: **Manrope**. Serif accent: **Instrument Serif**. Mono: **IBM Plex Mono**. The last three load via Google Fonts `display=swap` (`q_common.py` → `FONTS`). No `@font-face` needed; fallback stacks are declared in `theme.py` `FONT`. |
| Diagrams | `assets/js/dataflow.js` draws flow diagrams. The 5-step **pipeline** was SVG; rebuilt as HTML/CSS in this pass. |

Note: the prompts referenced Tailwind / `next/font` / npm, none of which exist here — fixes were adapted to this stack.

## 3. Verification method

- No headless browser available in this environment, so verification is **code-level**: grepping every gradient/`line-height`/`overflow`/`white-space`/margin rule, and `node --check` on the modified JS.
- JS syntax verified: `dataflow.js`, `motion.js` pass `node --check`.
- `python theme.py` / `python build_q.py` **could not be run** — no Python interpreter is installed on this machine (only the Windows Store stub). Therefore `tokens.css` was hand-synced to the `theme.py` token change, and the pipeline rebuild was implemented in `dataflow.js` (runs at page load, so the already-generated HTML is upgraded without a rebuild).

## 4. Remaining / recommendations

1. **Run the real build.** Install Python (or run on a machine that has it), then `python theme.py && python build_q.py`. This regenerates `tokens.css`/`brand.css` and every HTML page from the updated source, and re-runs the SEO registration. The JS-side pipeline fix works immediately; a rebuild is only required to also regenerate HTML from source.
2. **Browser sweep.** At 1440/1024/768/390px, confirm no horizontal scroll (`scrollWidth > innerWidth`) and re-check the hero gradient descenders with `prefers-reduced-motion` on (no SplitText mask) and off (mask active) — both paths are now covered by the padding-bottom fix.
3. **Contrast check** (a11y): the gradient stops on `--void` (#0d0e11) range from ~1.9:1 (gold `#eab308`) up to ~5:1 (sky `#38bdf8`). The serif line is large display text (≥24px), so WCAG large-text needs only 3:1 — the darker gradient tail is borderline; consider brightening the two middle stops if it fails a contrast audit. Gold-on-void focus/action elements already exceed 3:1.
4. **Fix the two copy typos** (items 11–12) in a future content pass.
